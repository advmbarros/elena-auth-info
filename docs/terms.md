# Termos de serviço

Última atualização: 11 de outubro de 2026.

Elena Memórias é um aplicativo pessoal para organizar informações no Google Drive do titular. Não oferece cadastro público nem assinatura comercial.

O titular deve autorizar somente a própria conta ou uma conta para a qual tenha permissão, selecionar as fontes utilizadas e manter credenciais em locais privados. Não é permitido usar o aplicativo para acessar dados de terceiros sem autorização.

O funcionamento depende de Google Drive, GitHub Actions e das ferramentas da interface utilizada. Cotas, indisponibilidade, atraso de agendamentos, revogação de permissões e falhas de captura podem interromper rotinas. Um snapshot válido não comprova que todas as conversas foram registradas.

O aplicativo não cobra assinatura. O responsável deve manter bloqueados gastos adicionais e respeitar as franquias gratuitas dos provedores. O projeto não garante gratuidade de serviços externos que o titular contratar separadamente.

Entradas e versões anteriores são preservadas para recuperação. O titular deve acompanhar os recibos e as lacunas informadas e manter cópias adequadas de informações importantes. O projeto não promete ausência absoluta de falhas.

O uso pode ser encerrado revogando a autorização Google e desativando as rotinas. Arquivos existentes permanecem na conta até serem removidos pelo titular.

A [política de privacidade](privacy.html) descreve o tratamento de informações. Alterações relevantes nestes termos serão registradas nesta página com a data de atualização.
