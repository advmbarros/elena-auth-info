# Elena Memórias

Elena Memórias é um aplicativo pessoal para registrar, organizar e recuperar memórias e referências no Google Drive da conta autorizada.

O aplicativo usa autorização OAuth do Google. O acesso é solicitado pelo titular da conta. O motor de consolidação processa os arquivos selecionados no Google Drive e gera snapshots de contexto. O código fica em um repositório privado; esta página contém apenas a descrição pública do aplicativo.

O uso é pessoal, sem cadastro público, assinatura ou venda de dados. A autorização pode ser revogada a qualquer momento na conta Google.
